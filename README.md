# Cybersecurity Assessment – 30 Questions

A multiple-choice assessment covering key concepts in cybersecurity, penetration testing, network analysis, Windows security, endpoint telemetry, and AWS cloud security.

## Overview

This repository contains a 30-question cybersecurity assessment designed for revision, self-study, or training. The questions cover both offensive-security concepts and defensive-security practices, along with networking, virtualization, and cloud infrastructure.

## Topics Covered

- **Cybersecurity fundamentals:** Initial Access, file-based attacks, IDN homograph attacks
- **Virtualization and networking:** Hypervisors, Bridge vs NAT networking
- **Web and application security:** Session-cookie theft, Remote Code Execution (RCE), file inclusion
- **Network analysis and packet crafting:** Wireshark display filters, Scapy, TCP packets
- **Penetration testing concepts:** Reverse shells, bind shells, stagers, singles, stages, Meterpreter, GTFOBins
- **Linux and Windows security:** Linux file permissions, `schtasks`, `netsh`, PowerShell execution policy
- **Cloud security (AWS):** SaaS/PaaS/IaaS, Security Groups, Elastic Load Balancing, VPCs, IAM policies and roles
- **Blue Team and endpoint detection:** Log telemetry, Windows Firewall, Snort rules, osquery

## Assessment Structure

The assessment contains **30 multiple-choice questions**:

| Questions | Main subject |
|---|---|
| 1–5 | Cybersecurity fundamentals, file attacks, virtualization, session cookies |
| 6–10 | Code vulnerabilities, Wireshark, Scapy |
| 11–18 | Shell types and payloads, Meterpreter, Linux permissions, Windows security commands |
| 19–26 | Cloud service models and AWS security configuration |
| 27–30 | Endpoint telemetry, Windows Firewall, Snort, osquery |

## Learning Objectives

After working through the assessment, learners should be able to:

- Explain common cybersecurity and attack concepts.
- Recognize selected security weaknesses in simple Python examples.
- Understand basic packet-crafting and traffic-filtering concepts.
- Identify the purpose of common Linux and Windows security tools.
- Distinguish AWS cloud service models and core access-control features.
- Understand introductory detection concepts involving logs, firewall rules, Snort, and osquery.

## How to Use

1. Open the assessment questions in the repository.
2. Answer each question before checking your notes or reference material.
3. Review any incorrect answers and research the related concept.
4. Practise technical commands only in systems and networks you own or are explicitly authorized to test.
